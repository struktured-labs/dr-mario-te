# DRHSV — the HSV leaf term in RTL (PREP; the ship decision waits on STEER5d)

**Spec** (h16-wt `RESULT_STEER5c.md` "RTL note"; Python `cascade_leaf5b_x`, w5[3] = 512):
−512 per virus in columns 3..5 at row < 9, folded into LeafEval's pre-scaled `matched60` accumulator in `S_COLWALK`.
The S_DONE2 combine gains no input and no pipeline stage.

## RTL (NES_MiSTer-drmario, branch `claude/hsv-leaf` @ `cce212a`, off the shipping 08f2343; pushed to `fork`)
- All changes sit behind `` `ifdef DRHSV ``, with every original line kept in the `` `else `` branches.
- **Flag-off identity:** `verilator -E -P` of the edited file == 08f2343's, byte for byte (893 lines).
- **Changes:**
  - `matched60`, `matched60_p` and `base_matched` become 15-bit two's complement (range −13,824..+2,304).
  - `S_COLWALK` has ONE accumulate site for both terms (two NBAs to one register in one cycle would drop one):
    `matched60 + (cover ? 48 : 0) − ((wr_ < 9 && wc ∈ {3,4,5}) ? 512 : 0)`.
  - `S_DONE2` adds `{matched60_p[14], matched60_p}`, sign-extended into the 16-bit wrap.
- **Delta path (CMD 6/7): no change needed, verified.** In this RTL the matched term's delta is closed-form
  (`dd_matched`, +48 per new cover), not mini-colwalked.
  - A non-clearing child never changes a virus cell, so its HSV == the parent's.
  - That HSV rides `base_matched`, latched from the parent's full CMD-6 `S_COLWALK`.
  - PHASE3 (the RTL delta result vs the HSV reference on each child) is the proof, and the `delta` mutant below
    shows it bites.
- **Quartus:** qsf = Childproof's archived `NES.qsf.used` + `set_global_assignment -name VERILOG_MACRO "DRHSV=1"`.

- **Bitexact gate with DRHSV:**
  - PHASE2's 256 failures are the same count with HSV on and off, and the first 20 printed cases are identical.
  - HSV is exercised: 542/948 leaf boards (count up to the maximum, 27) and 2,229/3,890 legal node children.
- **Firmware golden (py65):** 340/340 decisions (220 real HSV-heaviest game boards and 120 synthetic HSV-loaded
  boards). HSV moved 92 decisions.
- **Whole-search check:** 647/647 real-play boards agree, and HSV moved 21 root decisions vs w5=0.

- **Reference.** The HSV term is SPEC-FIXED in the gate: weight 512, rows < 9, cols 3..5, negative, added
  INSIDE the signed-16 combine. The wrap is modular, so `s16(_eval_rtl(...) − 512·n)` equals the RTL's single
  wrap, and the blessed `_eval_rtl` source is untouched. Only the cover weight is parsed from the RTL, so a wrong
  bound, column set or sign FAILS the co-sim instead of parsing into agreement.
- **Firmware golden.** The copro firmware is unchanged (77ec742c). The engine emulator and the golden mirror both
  read `nes_d3_golden.leaf_d3` patched with HSV. This proves the firmware's 16-bit arithmetic (Pass-0 keys, the
  temporal discount, expectimax sums, WIN compares, the reach pre-filter) handles the new, much more negative leaf
  range.
- **Whole-search check.** The sim brain STEER5c measured adds HSV after the base leaf's wrap. An RTL-exact twin
  (the 4 HSV addition sites wrapped to s16, generated by textual transform) makes identical root decisions, so the
  RTL implements exactly the brain the holdout measured. Real leaves span −266..+7,234 and HSV ≥ −13,824, so
  nothing reaches the wrap.
