## ★ THE TWO DEATH BOARDS — measured, stuck spawn capsule excluded
| | heights col 0..7 | occupancy | holes | edges (0,7) | spawn lane |
|---|---|---|---|---|---|
| g2 successor | `[0, 4,12,14, 7, 3,16, 0]` | **37/128 = 28.9%** | **19** | 0, 0 | 14 |
| g6 Childproof | `[0,12,14,11,14,15,13, 0]` | **44/128 = 34.4%** | **35** | 0, 0 | 14 |
1. **It dies with two-thirds of the bottle empty.** Neither death is a full bottle. g2 is two thin
   towers (a 2-wide at cols 2-3, a 1-wide at col 6 touching the ceiling) in an otherwise empty bottle.
2. **The structures are riddled with holes** — 19 and 35 covered empty cells. g6's "wall" is 44% air.
   The AI stacks UPWARD over gaps instead of filling them. That is precisely what a HOLES penalty
   prices, and the offline result (`R_HOLES` 20->80 cuts tap-out 41-51%) now has a mechanism you can
   see on the tape: make covering an empty cell expensive and it fills before it stacks.
3. **Columns 0 and 7 are EMPTY at both deaths.** The AI never used the edge columns. Across all eight
   games the two tap-out games show the largest centre-minus-edge height gap (+4.7, +1.7). Whether
   any term actively discourages the edges, or the placement enumeration under-samples them, is an
   open question worth one experiment.

## The "crazy fast endgame" is NOT on the tape
Owner's live impression of g8 (8-0): "cleared its end game crazy fast". HUD trace of the AI's last
30 s: `3 3 3 3 3 3 3 3 3 3 3 3 3 3 3 3 3 3 3 3 3 3 2 1 1 1 1 1 1 1 0` — **22 s parked on 3 viruses,
7 s on 1.** Seconds from <=8 viruses to 0, counting only seconds the board changed: g3 42, g5 34,
g7 60, **g8 69 — the SLOWEST of the four full clears.** What impressed was almost certainly the final
placement landing after a long stall, not the endgame's pace. The endgame is where this evaluator is
slowest per virus; that is the old dawdle concern, and the tape supports it rather than dispelling it.
