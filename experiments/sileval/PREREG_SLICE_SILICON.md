## Claim under test

DRP1SLICE cart `010f4ffe` (`roms/tcvc-p1slice.nes`, manifest
`roms/manifests/tcvc-p1slice.json`, built on `nmi-bound-126`) carries a sound
whole-frame NMI certificate (26,659 < 29,780) where ship `9fefaedb` has a

Mesen A/B: worst NMI 76%→29%, heavy frames (≥16k) 54→0, argmax provably

**Hypothesis:** the removed overrun tail improves NEAR-DEATH behavior on
silicon. The tail concentrates on tall same-colour boards — exactly the
near-death regime — where a shield-absorbed (skipped) game NMI is least
affordable.

## Endpoints

**Excluded by design: any tempo/duration/latency endpoint.** DRP1SLICE has two
documented phase dials (`tools/nmi126/NMI126_BOUND_REPORT.md`): one possible
AND-cancelled input frame per pill at publish, and a ≤8-frame board-drift
window mid-search. Both shift phase/tempo without being the mechanism under
test, so any tempo read is confounded. Per the phase-dial rule
(d131 lesson): tempo deltas between arms are EXPECTED and adjudicate nothing.

**E1 (primary): paired per-seed match outcomes.** For each pre-registered seed
s, both arms play the identical deterministic match sequence (seed → board +
128-capsule reserve is game-code-deterministic and identical across arms;
play does not step the LFSR — silicon-confirmed 2026-08-16). Record the
winner of each completed match in the cycle. Primary statistic: McNemar on
match-1 winner over paired seeds (discordant pairs only), direction = does
SLICE shift outcomes toward the arm-side the tail was harming. Matches 2..k
are secondary (same pairing logic holds — match-k's generation state depends
only on the seed — but they carry less exposure per seed).

Note the sharpened interpretation the paired design buys: the two carts are
argmax-identical, so on a given seed any outcome divergence is
timing-mediated (dropped/cancelled input frames, absorb events, phase dials).
A nonzero discordance rate is itself a witness that NMI timing reaches
behavior; the DIRECTION of discordance is the near-death claim.

**E1b (primary, conditional): near-death survival.** Offline-scored from the
sampled save-states: a match enters NEAR-DEATH when any sampled board for a
side has occupied cells in playfield rows 0–2 (top three rows, $0400/$0500
row-major). Among near-death entries, outcome = that side survives the
episode (returns below the line / wins) vs dies. Paired by seed × match
index × side. This is the regime the tail concentrates on; E1 unconditional
is retained because the 20 s sampling cadence can miss short near-death
excursions (a miss puts a real event into E1 but not E1b — stated, accepted).

**E2 (safety monitor, not superiority): wedge/softlock witness count.** A
wedge is proven ONLY by screenshot TIMEOUT or absent motion (3 captures
seconds apart, identical content hashes), never by frame content — and never
by a low goes/matches count alone (see VOID rules). Mesen showed 0 overruns
in both arms; expectation is 0=0. Rule-8 framing: the result is BOUNDED
EXPOSURE on this cart/core/box/seed-set, not an absence proof.

**E3 (descriptive only): per-cycle match tallies and virus-clear timelines** —
reported for context, no hypothesis test (tempo-adjacent).

## Design

- **Seeds:** `seeds_sileval.txt` — 240 seeds, generated by the committed
  recipe (Python `random.Random(139)`, unique 15-bit canonical classes,
  odd representative 2k+1 of the 2k≡2k+1 alias pair, class 0 excluded because
  seed 1 is the known degenerate constant seed, order shuffled with
  `Random(1139)`). Committed BEFORE any silicon row.
- **Injection:** seedjit pattern — inject $17/$18 into a pre-generation title
  save-state template, one template PER ARM, both captured on the NEW box and
  md5-pinned in `sileval.env` before row 1. The template pins cart+core+frame;
  a different template is a different experiment. Template validity gate: the
  same-seed / different-seed screenshot check from the 2026-08-16 seedjit
  validation must be reproduced on the new box for EACH template
  (same seed twice → 0.00% differing pixels; two seeds → >5% differing).
- **Arm order:** ABBA blocks over the seed list (seed i: block parity decides
  SHIP-first or SLICE-first) — kills slow drift (thermal, SD aging, time of
  day). Both arms of a pair run back-to-back before the next seed.
- **Cycle:** 360 s of play per arm per seed (~4–5 matches at the observed
  ~80 s/match), save-state + screenshot sample every 20 s, end-of-cycle
  state + screenshot always captured. One JSONL row per (seed, arm), written
  atomically (tmp+mv), fully resumable.
- **Per-row provenance (rule 11 — provenance is a mutable axis):** every row
  records: md5 of the cart file on the SD **hashed over ssh immediately
  before the MGL load** (hash the cart that boots), rbf md5, template md5,
  patched-state md5, seed, box IP, `/tmp/CORENAME` after boot, and the box
  identity sentinel (below). A row missing any of these is VOID.

## n and MDE honesty (sample-size-audit discipline)

Planned n = 240 paired seeds (≈2 days of unattended alternation at ~12.5 min
per pair). One interim reading at n=120 pairs is pre-registered (no other
peeking; no stopping for efficacy at interim — interim exists to catch VOID
conditions and instrument faults early).

What this n CAN and CANNOT detect (planning approximations, two-sided α=0.05,
power ≈ 0.8, McNemar on discordant pairs):

| true state | detectable at n=240? |
|---|---|
| discordance rate ≥ ~4% with ≥ ~80/20 direction split | YES (this is the "tail visibly reaches outcomes" case) |
| discordance ~10% with a 65/35 split | marginal (~55–65% power) |
| discordance ~10% with a 55/45 split | NO (n≈2,000+ needed) |
| near-death conditional effect | depends on near-death entry rate; if ~15% of matches enter near-death, E1b has only ~150–180 paired episodes at n=240 × ~4 matches — powered for LARGE conditional effects only (e.g. survival 50%→75%) |

If discordance is ~0 (arms play identical outcomes on silicon too), the
result is a NULL with a hard interpretation limit: it bounds the tail's
behavioral reach on THIS seed set/level, it does not prove tail harmlessness
(rule 8). That is a publishable outcome for this prereg, not a failure.

**Reading rule:** the scorer (`score_rows.py`) runs only after the arm is
complete (or at the registered interim n). Winner adjudication per match:
virus-count timeline (BCD-decoded $0324/$03A4) + mode timeline from sampled
states, corroborated by the end-of-cycle screenshot; a match whose winner
cannot be adjudicated from the artifacts is scored UNREADABLE (reported, not
silently dropped; >10% UNREADABLE voids the endpoint, fix the instrument).

## VOID conditions (any of these voids the affected row/run, never bent post hoc)

1. **Cart-hash mismatch:** pre-load ssh md5 of the SD cart ≠ the registered
   arm md5 → row VOID, run halts (the watchdog-MGL-fallback lesson).
2. **Template mismatch:** template md5 ≠ pinned value → all subsequent rows
   VOID (different experiment).
3. **Reload/injection failure:** any seedjit step fails (scp, load_core, F1
   restore) → row VOID, retried once, then halt-and-report.
4. **Box identity failure:** `/media/fat/SILEVAL_BOX_ID` sentinel absent, or
   resolved IP equals the live soak box → HARD STOP before any command.
   (Both MiSTers ship the same default MAC `02:03:04:05:06:07` — ARP/mDNS
   discovery CANNOT distinguish them; the driver takes an explicit IP only
   and never calls `mister_ip.sh`.)
5. **Low-goes artifact:** a cycle reading "goes≈0 / no matches" is NOT a cart
   property until (a) re-run of the same arm AND (b) a same-runner positive
   control (the other, known-good arm in the same session) reproduce it.
   Three prior occurrences were all instrument artifacts.
6. **Wedge adjudication:** wedge only by screenshot-timeout / no-motion rule;
   busy-heuristics alert but never decide.
7. **Interpreter/harness absence is not pass:** missing scorer input, empty
   rows dir, 0-byte save-states (save/scp race — poll remote size+mtime
   before scp) → the affected samples are VOID, not zero.
